# 開発環境管理ツール メモ

## 目的

Web画面から開発用Dockerコンテナの状態を確認し、起動・停止などの基本操作を行えるようにする。
ローカルPC上のDocker Engineを管理対象とし、開発環境をコマンド操作なしで扱いやすくする。

## 想定する利用者

- 複数の開発環境を使い分ける開発者
- Docker操作に慣れていないメンバー

## v1の機能

- Dockerデーモンに接続できるかを画面で表示する
- コンテナ一覧を表示する
  - コンテナ名、イメージ名、状態、公開ポートを確認できる
- コンテナを起動・停止・再起動する
- 操作前に対象コンテナと実行内容を確認する
- 操作結果とエラー内容を画面に表示する
- コンテナ詳細で環境変数、ポート設定、マウント設定、直近500行のログを確認する
- 操作履歴をローカルに永続保存し、再起動後も確認できるようにする
- Composeラベルを持つ既存コンテナは、プロジェクト単位で一括起動・停止・再起動できる
  - 一括起動は `created` / `exited`、一括停止・再起動は `running` のコンテナだけを対象とする
  - 操作前に対象コンテナと対象外コンテナ・理由を表示し、結果はコンテナごとに確認できる

## 管理対象

- アプリケーションを利用する同一PC上のローカルDocker Engine
- ローカルDocker Engine上の既存Dockerコンテナ
- Composeラベルを持つ既存コンテナ群
- 単一利用者による利用（ログイン機能なし）
- 本番環境のDockerホストは管理対象にしない

## v1の対象外

- コンテナの作成・削除
- イメージ、ボリューム、ネットワークの変更操作
- Compose定義ファイルの探索、依存関係の解釈、`docker compose up/down`
- Compose定義に基づくコンテナの作成・削除
- 複数Dockerホストの登録・切替
- ログイン、ユーザー管理、権限管理
- 外部ネットワークへの公開運用

## Web画面のイメージ

- ダッシュボード: Dockerの接続状態と、起動中・停止中コンテナの件数
- コンテナ一覧: 状態で絞り込み、各行から起動・停止・再起動を実行
- コンテナ詳細: 環境変数、ポート、マウント、ログなどを確認
- 操作履歴: いつ、どのコンテナに、どの操作をしたかを確認

## 技術的な考え方

- WebアプリのバックエンドからDocker Engine APIを利用してコンテナを操作する
- バックエンド自身をDockerコンテナとして動かす場合は、Dockerソケットまたは安全に構成したAPI経由でDocker Engineへ接続する
- Docker操作の権限は強力なため、接続先と操作対象をローカルDocker Engineに限定する
- 開発環境向けを前提とし、本番環境のDockerホストを直接管理対象にしない

## 非機能・安全面

- 操作前に対象コンテナと実行内容を明確に表示する
- 起動・停止・再起動の実行結果を操作履歴として残す
- Docker接続エラーや操作失敗時に、次に確認すべき内容を案内する

## 将来の検討事項

- 複数Dockerホストを扱う場合の接続先管理
- Compose定義を解釈し、コンテナの作成・削除まで扱う高度な操作の範囲
- 公開・複数利用者対応時の認証・権限管理
- コンテナ作成・削除を追加する場合の安全な確認・権限制御
- 採用するフロントエンド・バックエンド技術
