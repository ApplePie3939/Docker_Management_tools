# 開発環境管理ツール 要件定義（v1）

## 1. 目的

Web画面からローカルPC上のDocker Engineへ接続し、開発用Dockerコンテナの状態確認と基本操作を行えるようにする。Dockerコマンドに慣れていない利用者も、開発環境を安全かつ分かりやすく操作できることを目的とする。

## 2. 対象利用者・対象環境

- 複数の開発環境を使い分ける開発者
- Docker操作に慣れていない開発メンバー
- v1の管理対象は、アプリケーションを利用する同一PC上のローカルDocker EngineとDockerコンテナに限定する
- v1は単一利用者を前提とし、ログイン機能は提供しない
- 本番環境のDockerホストは管理対象にしない

## 3. 機能要件

### 3.1 ダッシュボード

- Dockerデーモンへの接続可否を表示する
- 起動中コンテナ数と停止中コンテナ数を表示する
- 接続できない場合は、エラー内容とDocker Engineの起動状態など次に確認すべき内容を案内する

### 3.2 コンテナ一覧

- 管理対象コンテナを一覧表示する
- 各コンテナについて、以下を表示する
  - コンテナ名
  - イメージ名
  - 状態
  - 公開ポート
- 状態でコンテナを絞り込めるようにする
- 各行から起動・停止・再起動の操作を開始できるようにする

### 3.3 コンテナ詳細

- 選択したコンテナについて、以下を読み取り専用で表示する
  - 環境変数
  - ポート設定
  - マウント設定
  - 標準出力・標準エラーの直近500行のログ

### 3.4 コンテナ操作

- コンテナを起動、停止、再起動できるようにする
- すべての操作前に、対象コンテナと実行内容を明示した確認ダイアログを表示する
- 確認の取消時はDocker操作を実行しない
- 操作完了後に成功・失敗を画面に表示し、一覧およびダッシュボードの状態を最新化する
- 操作に失敗した場合は、Docker Engineから得られたエラー内容と、利用者が次に確認すべき内容を表示する

### 3.5 操作履歴

- 起動・停止・再起動の実行結果を履歴として記録する
- 各履歴には、日時、対象コンテナ、操作種別、成功・失敗、結果メッセージを含める
- 操作履歴はローカルに永続保存し、アプリケーション再起動後も確認できるようにする

## 4. 非機能・安全要件

- Docker操作はバックエンドを介してDocker Engine APIを利用する
- バックエンドをコンテナで実行する場合、Dockerソケットまたは安全に構成されたAPI経由でDocker Engineへ接続する
- Docker操作は強い権限を伴うため、操作対象と接続先をローカルDocker Engineに限定する
- Docker接続エラー、操作失敗、ログ取得失敗を利用者に分かる形で表示する

## 5. v1の対象外

- コンテナの作成・削除
- イメージ、ボリューム、ネットワークの変更操作
- Docker Composeプロジェクトの起動・停止
- 複数Dockerホストの登録・切替
- ログイン、ユーザー管理、権限管理
- 外部ネットワークへの公開運用

## 6. 将来拡張：公開・ログイン機能

将来的に本ツールをネットワーク越しに公開する、または複数利用者で利用する場合は、ログイン機能を追加する。その際は、少なくとも以下を満たすことを要件とする。

- 利用者は認証済みでなければ、画面の閲覧およびDocker操作を実行できない
- 利用者ごとに操作可能なDockerホスト・コンテナ・操作種別を制限できるようにする
- 管理者と一般利用者など、役割に応じた権限管理を行えるようにする
- 操作履歴には実行者を記録し、監査できるようにする
- インターネットへ公開する場合はTLSによる通信暗号化を必須とする
- DockerソケットおよびDocker Engine APIを外部へ直接公開しない
- 認証情報・セッション情報を安全に保管し、未認証アクセス、総当たり試行、不正なクロスサイトアクセスを防止する
- 公開対象は開発用途に限定し、本番Dockerホストを直接操作できる構成は採用しない

## 7. 受け入れ基準

- Docker Engineが起動中・停止中のどちらの場合も、接続状態と必要な案内を表示できる
- コンテナ一覧で名前、イメージ、状態、公開ポートを確認し、状態で絞り込める
- コンテナ詳細で環境変数、ポート、マウント、直近500行以内のログを確認できる
- 起動・停止・再起動は確認後にのみ実行され、成功・失敗が画面に表示される
- 操作後、一覧とダッシュボードの情報が更新される
- 操作履歴が再起動後も保持される
